# 产品体验修复记录

日期：2026-09-09。对应逐页体验评审清单。

## 已实施

- 首页固定电站上下文，增加资料入口、下拉和可见刷新。趋势有独立加载、失败重试和请求序号保护；风电默认风速，光伏默认辐射。
- 地图区分搜索中、空结果和失败，废弃过期响应；清理临时位置，等待绘图回调后才显示成功，超时支持重试。

- 报告移除无依据的满负荷和检修建议，区分辐射资源与转换效率、夜间与次日。公开电站当日报告按 10 分钟按需重生成，补充生成时间、数据时间、电价和碳因子，并支持用户主动分享。
- 设置分为使用帮助、数据与隐私、关于，显示真实版本和反馈上下文。说明页补实际缓存周期、覆盖限制、计算示例及来源链接。
- 绝对时间统一标明北京时间；趋势横轴标明电站当地时间。超过 60 秒返回页面按需刷新，失败保留数据并提示。放大返回、分段与影像操作区域。

## 图片路径修复

容器内图片存在，但共享网关剥离了 `/enersight` 前缀，与 FastAPI 静态挂载不一致。代理保留前缀后，公网图片与健康接口均返回 200。生产目标配置已备份，通过 `nginx -t` 后重载。新增静态图片前缀回归测试。

公网入口强制 HTTPS，但 ALB 未可靠提供原协议头，导致图片地址生成 HTTP 再跳转。业务代理显式传递 HTTPS，并保留 Host 等代理头，避免图片加载依赖重定向。

模拟器已检查首页、报告、设置、目录、详情及图层面板。风电详情默认风速，查看资料没有切换当前电站；图层面板不再与地图工具和详情叠在一起。原生地图模拟器仍出现内部渲染错误，当前以失败状态呈现，不能据此宣称真机贴图通过。

## 地图图层模拟器补充修复（2026-09-09）

用户确认问题发生于电脑模拟器。此前图层选择会生效，但模拟器的原生 `addGroundOverlay` 未完成绘制，只有错误提示无法满足预览需要。

现在为 `platform=devtools` 增加真实后端图片预览，按北向、无倾斜地图的墨卡托视野定位图片；手机保留原生贴图。预览使用图片加载事件确认成功，失败可重试，旧请求不能覆盖新选项；缩放与中心变化重新取视野，用户拖动时移除旧覆盖。原生端兼容回调与 Promise，使用递增覆盖物 ID 避免切换时复用冲突。

模拟器已目视确认温度色阶、风速色阶、云图及观测时间、缩放后的更新。风场仍是静态风速分布，不提供粒子动画。预览以图片范围贴合地图，不代表真机投影精度已验收。新增 3 项投影回归测试，核心测试共 30 项。

## 地图空坐标渲染错误修复（2026-09-09）

`Cannot read property 'lat' of undefined` 的堆栈为 `pointsChanged → fitBounds → getNorth`。业务未使用 includePoints，但 Taro 4.0.9 默认模板生成 `include-points=[]`，微信 3.16.2 模拟器在处理空范围时异常。增加构建插件移除本项目未使用的自动适配坐标属性，保留中心点与 scale 控制；不是屏蔽异常，也不修改 node_modules 或手工修改 dist。未来若需自动适配坐标，使用非空且校验过的 MapContext.includePoints。

验证：类型检查、微信构建通过，产物地图属性不含 include-points；模拟器重新进入地图，红色 lat 错误不再出现，温度图层与电站显示正常。

# 晴川观象 UI/UX 评审

日期：2026-09-09。范围：五个主 Tab、站点详情及分析报告。依据：微信开发者工具实际界面、交互及源码。此次为评审，未修改业务界面。

## 整体判断

主流程已经打通，公共目录直接查看、统一浅色背景和卡片、加载与错误反馈都有基础。当前仍呈现出早期产品特征：大指数和彩色入口较强，解释与上下文很弱；部分可点击外观没有对应行为。目标应是清晰、可靠、克制的气象分析工具。

保留：共享目录、五个熟悉的底部导航位置、站点跨页同步、现有蓝色主色。首轮不需要重做全部页面或更换技术方案。

## 优先问题

### P1：数据表达必须可信

- 首页实际显示“0 分、较差”，预警页无预警时固定写“发电条件正常，未来 24 小时无异常天气”。没有触发预警不代表发电条件好，应改为“当前未触发预警”，同时显示监测电站、检查时间和覆盖范围。
- 报告实际以绿色突出“今日发电条件较差”。结论颜色应随等级变化，或用中性色，不固定使用成功色。
- 公共电站转换时固定 `status="normal"`，客户端显示“运行正常”。目录的运营状态不能代表实时设备健康，改为“目录状态：运营中”，明确没有接入设备遥测。
- 首页、地图、详情、报告中的部分字段使用 `?? 0`。缺失值应显示“— / 暂无数据”，避免误认为 0℃、零风速或零收益。
- 增加指数解释：综合什么因素、针对光伏还是风电、更新时间与数据来源。报告标识气象推算和规则/AI生成方式，不将其展示为实测。

### P1：消除无效入口和虚假状态

- 首页“查看更多”和指数问号没有绑定实际操作；报告“查看详细分析”“数据摘要—查看更多”同样存在未绑定行为。
- “我的”页大多数设置项没有处理函数，却都显示右箭头；“预警通知：已开启”为静态文案。
- 已实现的行为保留并提供反馈；未实现的功能暂移除入口。仅在取得对应授权/订阅状态后显示已开启。隐私说明与关于页应实际可访问。

### P1：提高关键文字可读性

源码正文 14px、说明 11px、微文案 10px，快捷入口副标题仅 9px，图表刻度 10px。模拟器当前缩放为 75%，视觉检查结合了源码尺寸，不能把截图像素当作真实手机尺寸。

建议首轮字号：正文和列表 14–16px，说明 12–13px，图表刻度 11–12px；四列指标无法容纳时改为两列。去掉没有信息增量的小副标题，给数据说明留空间。

`#9CA3AF` 对白色的计算对比度约 2.54:1，对浅蓝背景约 2.40:1。用于重要单位、时间与说明时过浅。将关键次要文字加深；普通文本以 4.5:1 为验收目标。参考：[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

### P2：导航与图标统一

`gen-tabbar-icons.mjs` 当前采用 24×24 坐标、2.25 描边，并在选中状态添加 20% 填充；图形几乎铺满画布，视觉重量较大。

建议稿：24 逻辑尺寸，1.6–1.75 描边，统一圆角端点与视觉占用；先以 1.75 验证手机效果。选中态主要变蓝，保持相同线宽，取消普遍填充；点击区域不跟着图标缩小。“站点”改成站点/设施语义图标，现有折线图更像统计入口。“我的”若保持工具设置属性，可改称“设置”，不必为减少数量而立即重排 Tab。

### P2：目录与地图提高查找效率

目录目前只有容量排序，长名称单行截断、中英文地名混排，50 条之后才出现翻页。建议搜索与筛选保持可达，加入省市筛选、最近浏览；列表名称最多两行，中文地区单独一行，容量是次要信息。点击整行即可查看，末尾简洁箭头即可。最近浏览不改变全员共享目录，不恢复“添加站点”。

地图右侧同时堆叠多层工具，标记与站名容易拥挤。建议图层折叠成单一入口、标记聚合、底部信息面板可收起；图层要显示更新时间、加载中与加载失败状态。首次打开站点目录或明确提供电站切换，比默默选择最大容量电站更容易理解。

## 逐页调整

| 页面 | 建议结构 |
| --- | --- |
| 首页 | 当前电站与地区 → 发电适宜度结论及依据 → 关键气象 → 趋势；精简重复快捷入口 |
| 地图 | 电站/地区搜索 → 地图 → 可折叠图层与站点摘要，地图保留主要可视面积 |
| 预警 | 当前电站、检查时间 → 当前风险 → 卫星辅助 → 历史记录；双空态合并压缩 |
| 电站目录 | 搜索、地区、类型 → 最近浏览 → 全部电站；支持可辨识长名称和列表位置保留 |
| 我的/设置 | 只显示已实现的偏好设置、数据来源、隐私说明、反馈和关于；品牌不冒充用户资料 |
| 详情 | 展示完整名称，气象/模型参数与来源；避免与首页完全重复 |
| 分析报告 | 先结论与原因，再分时预测与建议，最后估算指标和口径；结论色与语义一致 |

## 主观启发式评分

这是设计检查评分，不是用户研究或转化率测量。

| 维度 | 0–4 分 | 主要理由 |
| --- | --- | --- |
| 状态可见 | 2 | 有加载反馈，数据时间和预警对象不充分 |
| 现实匹配 | 2 | 运营中/设备正常、无预警/发电条件好混淆 |
| 控制自由 | 3 | 导航、返回和切换基本成立 |
| 一致性 | 2 | 图标和语义色不一致 |
| 防错 | 2 | 共享记录写保护已做，缺失值展示仍误导 |
| 识别优于记忆 | 2 | 预警缺电站上下文，指数缺解释 |
| 效率 | 2 | 搜索可用，缺地区筛选与最近浏览 |
| 简约与层级 | 2 | 大分数和彩色入口挤压解释文字 |
| 错误恢复 | 2 | 有重试，但 503 一律显示区域暂无数据 |
| 帮助 | 0 | 可见帮助入口和隐私等尚未闭环 |
| 合计 | 19/40 | 核心流程可用，发布前应处理主要误导与无效入口 |

## 用户情境

- 首次使用者：不理解为何默认是甘肃电站，不理解 0 分，点击问号又没有解释。
- 经常看同一区域的用户：需要反复输入关键词，在容量排序的长列表里找站；缺最近浏览和地区筛选。
- 在户外单手查看或视力较弱的用户：9–11px 浅灰说明难读，地图工具过密。手机字号放大、触控和读屏仍需专项实测。

## 实施顺序与验收

1. 图标减重、字号/对比度、语义色和状态文案统一；清除无效入口与假状态。
2. 打磨首页解释、预警电站上下文、目录地区筛选与最近浏览。
3. 优化地图浮层和聚合、报告阅读、弱网恢复。

验收包括：不同电站类型、超长名称、无预警、低适宜度、缺数据、请求失败、重新进入、大小屏真机；图标在真实手机尺寸下清晰，用户能说清当前看哪座电站、数据多久前更新、结论从何而来。

自动检测器在 Taro TSX 源码上返回 0 条，不代表设计没有问题；本次发现主要来自原生模拟器与源码核对。未注入浏览器覆盖层，未启动临时网页服务。人工评估先记录，再运行检测器，采用单人顺序评审；尚未做真实用户测试。

## 首轮改造落实（2026-09-09）

已实施连续白底目录、两行名称、独立地区/容量、固定搜索与筛选、地区和名称排序、滚动加载、本机最近浏览；Tab 图标 1.75 描边并重绘电站图标；首页/详情两列指标、缺测空值、指数解释和更新时间；预警返回电站与检查时间；报告说明实际生成方式并使用中性色结论；设置只保留真实入口；地图图层折叠、标记分组与详情面板收起。后台回归 175 项通过，前端核心 24 项通过。地图 ground-overlay 的真实显示仍须真机验证，模拟器无法代表卫星贴图效果。

配套接口已通过 GitHub 流程 34310050615 发布生产，健康检查正常。模拟器验证上海地区 173 座、组合光伏筛选 160 座；说明页可打开，地图面板可收起。底部文字对比度与状态栏文字颜色也已统一。

## 第二轮：地图与报告减负（2026-09-09）

地图图层改成遮罩底部面板，选中后关闭，当前站点短标注不再横跨地图。首页与详情共用白底轻量评分摘要。报告改为连续章节，风险紧跟结论，分时信息改为纵向行、估算指标改为两列；详情突出完整名称与容量，前置报告/地图操作，地区与坐标独立展示。两页返回导航保持固定。

模拟器已验证图层展开与切换、两座长名称电站详情、无风险及有风险报告、长页面滚动与页尾。联动验证发现并修正路由编码进入站点状态导致首页 404，以及隐藏页面 Canvas 误用浏览器 DOM 查询的异常。气象贴图真机显示仍不在模拟器验收范围内。

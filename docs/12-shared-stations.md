# 共享电站目录

所有用户默认浏览平台收录的运行中电站，无需上传或添加。站点页支持名称、省市、业主搜索和光伏、风电筛选，每页 50 条，翻页可访问完整目录。点击条目直接查看详情，同时记住本机当前选择；首页、地图、预警、报告使用同一座电站。首页未选择时默认展示按装机容量降序排列的第一座公开电站。

首页和地图标题可切换到电站目录。地图上的公开电站提供“查看电站”入口，不再创建个人副本。公开电站由平台统一维护，普通用户不能修改或删除。

## 服务端与兼容

新增 `GET /v1/stations/public`，支持 `keyword`、`type`、`limit`（1–100）、`offset` 与 `coord`。响应 `counts` 为全部运行中电站分类计数，`total` 为当前筛选总数，`has_more` 表示还有下一页。按装机容量降序、ID 升序固定排序。鉴权要求不变，不以用户 ID 过滤公共目录。

详情、首页、地图、预警和报告通过目录 ID 直接解析公开电站，不插入 `stations` 表。原个人站点 API 暂保留以兼容历史客户端，原有账号隔离不变，小程序已移除添加、编辑与删除入口。目录为空时服务端可兼容历史个人站点；正常有目录时默认优先公共电站。

预警、报告、发电记录的 `station_id` 扩展为 24 字符，迁移版本 `b72e69410cfa`。公开电站分析按访问计算，不对近两万座电站同时启动定时采集。没有积累的历史发电与减排指标保持空值；天气与出力属于气象推算。

当前选择使用新存储键 `enersight_current_public_station`，避免旧的个人站点选择影响首次共享目录体验。

## 验证

后端回归覆盖两个不同账号的相同目录、分页无重复、类型与中文搜索、参数边界、通配符转义、无需建站的默认首页与直接详情，以及公共站点修改和删除保护、退役条目过滤。生产部署前 CI 使用 PostgreSQL 16 验证迁移与 24 字符目录 ID 的预警、报告、逐日发电写入。

生产版本已于 2026-09-09 发布，GitHub 流程 34307881115 成功；线上 `/ready` 正常。开发者工具实测目录显示 18,764 座，中文搜索、直接查看详情与返回首页切换均已验证。首页重新显示时重建趋势画布，避免隐藏页面初始化尺寸为零造成空图。

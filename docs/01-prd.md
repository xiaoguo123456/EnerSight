## 一、产品定位

EnerSight 是一个基于：

- 气象数据
- 卫星遥感数据
- 地理空间数据
- AI分析能力

的新型能源环境分析平台。


目标：

帮助用户快速了解某一区域：

- 当前新能源环境
- 未来气象变化
- 云层影响
- 发电风险

### 2. 新能源环境指数


展示：

新能源环境指数。


示例：

```
新能源环境指数

92分

今日适宜发电，下午存在轻度云层影响
```


构成：

| 元素 | 说明 |
| --- | --- |
| 分数 | 0 – 100 分 |
| 等级 | 优秀 / 良好 / 一般 / 较差 |
| 一句话结论 | AI 生成，替代等级文字单独展示 |
| 说明入口 | 「?」图标，展示归因明细 |


含义：

```
今天能发出这个站点潜力的百分之多少
```

由物理出力模型算出，不是因子加权评分。
辐射、云量、温度、风速的影响全部通过模型进入。


说明弹窗展示**归因**而非权重：

```
今日 82 分

辐射条件   云层使辐照降至晴空的 64%    −33 分
温度损失   32℃ 高温使组件效率下降      −6 分
散热增益   4.5 m/s 风速改善散热        +1 分
```

算法见 [07 §一](./07-metrics.md)。

### 4. 气象趋势


支持：

- 24小时
- 7天


24 小时趋势：

- 指标切换：辐射（W/m²）/ 风速（m/s）/ 云量（%）
- 折线 + 面积图
- 点击数据点显示悬浮值（如 14:00 · 680 W/m²）并高亮该时刻
- 横轴 00:00 – 24:00
- 「查看更多」进入完整趋势页


三模式区间与预报演变（2026-09-18，口径见 [19 §一、§二](./19-forecast-uncertainty-and-observations.md)）：

- 模型选择器默认「三模式」：ECMWF、ICON、GFS 各算一遍，大数字取当天日电量居中的那家
- 大数字下两行，格式统一为「文字 + 灰标签」：
  - 「区间 51–105 MWh」+ 分歧度标签（模式一致 / 模式分歧 / 分歧很大）；下一行三家并列，居中那家加粗
  - 「ECMWF 演变 90 → 100 → 105 MWh」+ 收敛度标签（已收敛 / 仍在波动 / 来回摇摆）；点「详情」展开历次起报与两段说明
- 预测功率图画三家包络带；有带时主曲线不画面积渐变，否则带的下沿看不出来
- 两个标签都是中性灰：说的是预报有多稳，不是天气好坏，不套优良中差的配色
- 「全部电站」视图不做三模式，选择器里不出现这一项，已选的显示实际用的「自动 · ECMWF」，切回本站仍是三模式
- 三模式的起报时刻统一报三家中最早的一家，选择器写「最早起报 08:00」，ⓘ 列出三家各自的起报

实测订正（2026-09-18，口径见 [19 §三](./19-forecast-uncertainty-and-observations.md)）：

- 我的电站的预测卡底部有「记一笔」：日电量或月电量、发电量或上网电量，一步提交，提示模型同期电量
- 订正生效时大数字旁出现「实测订正」徽章，电量、曲线、当前功率都乘了系数，发电适宜度不变
- 电站详情「实测对账」页：订正状态（模型偏高 / 偏低多少、按几倍修正、订正前后逐日误差、开关）与记录列表

数据导出（CSV）：

- 预测功率卡「导出七天 CSV」：未来 7 天逐 15 分钟可发功率，有限电规则时增加预计上网功率；全目录为预测功率合计
- 气象趋势「导出气象 CSV」：24 小时辐射、10 米风速、云量按时刻对齐
- 数值为基础单位（kW、W/m²、m/s、%），时间为电站当地时间，缺测留空不写 0；带 BOM，Excel 直接打开
- 小程序没有文件下载入口，生成文件后以文件消息发送到聊天（可发给文件传输助手），失败时可复制表格内容；H5 直接下载

| 项 | 示例 | 辅助说明 |
| --- | --- | --- |
| 云团距离 | 80 km | 距苏州光伏站 |

### 4b. 卫星辐照实况（2026-09-20）


预警卡之下一张「卫星辐照实况」卡，口径见 [19 §四](./19-forecast-uncertainty-and-observations.md)：

- 辐照大数字 + 「晴空的 44%」+ 观测时刻（葵花 10 分钟一帧，实况约半小时前）
- 直射 / 散射一行
- 署名「JAXA / P-Tree 葵花卫星」，**不能删**，与云图的「日本气象厅」同理
- 无预警时这张卡是本页唯一的 Hero，数字放大；有预警时退成普通卡
- 夜间显示「夜间没有可见光反演」，过期或拿不到显示对应说明，不显示 0
- **只展示**：当前功率与当日累计仍用预报，等回测达标（[07 §8.1](./07-metrics.md)）再切

### 2. 添加站点

两条路：浏览公开目录，或自建。

- **公开目录**仍是主路径：全国近两万座光伏 / 风电场站的位置、容量、业主已有公开数据
  （[04 §七](./04-data-specification.md)），按月自动同步，选择即可查看，不复制个人副本。
- **自建电站**：目录里没有的电站自己添加，仅本账号可见。站点页顶部分「公开目录 / 我的电站」
  两段，我的电站段内有「添加电站」，「我的」页也有入口。每用户上限 10 座。

自建表单字段：名称、类型（光伏 / 风电）、装机容量（kW，交流侧）、经纬度、可选的出力模型
参数（倾角 / 方位角 / 轮毂高度）、可选的出力约束（[17 §四](./17-user-stations-and-outlook.md)）。

经纬度三种来源：

| 来源 | 坐标系 | 说明 |
| --- | --- | --- |
| 当前定位 | GCJ-02 | `wx.getLocation`，拒绝授权后仍可用其余两种 |
| 地图选点 | GCJ-02 | `wx.chooseLocation`，选到的地名可带入名称 |
| 手动输入 | 用户选择，默认 WGS84 | GPS 设备、谷歌地图读数选 WGS84；高德、腾讯、百度读数选 GCJ-02 |

提交时带 `coord`，服务端转成 WGS84 存储；客户端不做坐标转换。

此前「站点只从公开电站目录添加」的口径于 2026-09-12 撤销，原因与影响见
[17 §一](./17-user-stations-and-outlook.md)。

## 七、AI分析报告


入口：

首页快捷入口、地图 AI 提示条、站点详情快捷操作。


报告头部：

站点信息 + 报告日期 + 生成时间。


内容：

### 综合判断

例如：

```
今日适宜发电，
下午存在轻度云层风险。
```

附整体建议说明。


### 今日情况

按时间轴分析三段：

| 时段 | 时间区间 | 输出 |
| --- | --- | --- |
| 上午 | 06:00 – 12:00 | 天气概况 + 发电条件 |
| 下午 | 12:00 – 18:00 | 天气概况 + 发电条件 |
| 晚间 | 18:00 – 24:00 | 天气概况 + 对次日影响 |

时间轴节点按该时段风险等级配色。


### 风险提醒

展示当日主要风险及应对说明，可进入预警中心查看更多。


### 运营建议

编号列表输出，通常 3 条，每条为可执行动作。


### 数据摘要

四宫格，均带昨日环比：

```
发电量    等效利用小时    CO₂减排    收益预估
```

### 全目录历史趋势导航

首页仅保留“本站预测 / 全部场站”一层范围切换。历史趋势入口放在预测卡标题行右侧，
与“本站”卡的“电站资料 ›”同一位置，两张卡结构一致；进入独立二级页面，历史页保留
模型选择和周/月/年周期选择，返回后恢复首页的全部场站范围。历史页不出现今日预测的
刷新按钮或重复范围切换。

有地区筛选时，入口把当前地区一并带过去，历史页显示该范围并提供“看全国”。


### 全目录按地区筛选

全部场站下方的区域贡献列表，点击省份即在本页筛选，可多选，再点取消。筛选生效时卡片上方
出现一条筛选条，显示已选地区与“清除”，标题跟着写明所选地区。清除后回到全国，不发请求。

- 首次选中（0 → 1）滚回页首，让用户看见数字变了；之后的切换不滚。
- 单选时筛选条右侧给“查看该省电站 ›”，进入站点列表并带上该省筛选；多选时不出现。
- “地区待补充”不可选。
- 历史趋势跟随筛选：入口带上所选地区，历史页按该范围汇总，可切回全国。
- 筛选不跨会话记忆：记住了用户下次进来会看到一个自己忘了开的筛选。

### 全目录风光变化

「全部电站」增加明日/所选日两轮预测的光伏、风电变化、重点时段、区域变化榜与风光联动；预报演变和已生成模型的分歧在卡内展开。「卫星云图」进入地图并适配所选省份全域，使用真实卫星帧；「站点短临」进入预警页。区域变化榜点击省份沿用现有地区筛选，不设置关注或提醒。只对同一批目录场站的可比签发给变化值，绝对电量仍标「平台目录估算」。完整口径见 [20](./20-fleet-signals.md)。

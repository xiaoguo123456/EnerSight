## 一、产品定位

EnerSight 是一个基于：

- 气象数据
- 卫星遥感数据
- 地理空间数据
- AI分析能力

的新型能源环境分析平台。


目标：

帮助用户快速了解某一区域：

- 当前新能源环境
- 未来气象变化
- 云层影响
- 发电风险

---

### 2. 新能源环境指数


展示：

新能源环境指数。


示例：

```
新能源环境指数

92分

今日适宜发电，下午存在轻度云层影响
```


构成：

| 元素 | 说明 |
| --- | --- |
| 分数 | 0 – 100 分 |
| 等级 | 优秀 / 良好 / 一般 / 较差 |
| 一句话结论 | AI 生成，替代等级文字单独展示 |
| 说明入口 | 「?」图标，展示归因明细 |


含义：

```
今天能发出这个站点潜力的百分之多少
```

由物理出力模型算出，不是因子加权评分。
辐射、云量、温度、风速的影响全部通过模型进入。


说明弹窗展示**归因**而非权重：

```
今日 82 分

辐射条件   云层使辐照降至晴空的 64%    −33 分
温度损失   32℃ 高温使组件效率下降      −6 分
散热增益   4.5 m/s 风速改善散热        +1 分
```

算法见 [07 §一](./07-metrics.md)。

### 3. 实时环境数据


四宫格展示：

| 指标 | 主值 | 辅助信息 |
| --- | --- | --- |
| 天气 | 32 ℃ | 天气现象文案（晴转多云） |
| 风速 | 4.5 m/s | 较昨日 ↑12% |
| 云量 | 35 % | 较昨日 ↓8% |
| 辐射 | 620 W/m² | 较昨日 ↑6% |


环比要求：

每项指标需与昨日同期对比，缺少昨日数据时隐藏环比标签。


> 湿度、风向不在首页四宫格展示，作为站点详情与 AI 分析的输入数据保留。

### 4. 气象趋势

- 24小时

- 横轴 00:00 – 24:00
- 「查看更多」进入完整趋势页

## 五、预警 Alert


功能：

监测新能源风险。


### 1. 页面结构

标题「预警中心」，副标题「实时监测 · 精准预警 · 助力稳定发电」。


### 2. 等级筛选

```
全部    轻度    中度    重度
```

轻/中/重分别以绿、橙、红状态点标识。


### 3. 卫星云图

- 左上角：数据类型 + 观测时间（如 2024-07-20 14:00）
- 地图内：站点位置标记
- 右下角：云量强度图例（低 — 高）
- 右上角：全屏查看


### 4. 当前预警


卡片包含：

- 风险等级徽章
- 发布时间
- 预警标题
- 成因与影响说明


云团外推三宫格：

| 项 | 示例 | 辅助说明 |
| --- | --- | --- |
| 云团距离 | 80 km | 距苏州光伏站 |
| 移动方向 | 东北 | 向东 / 东北方向移动 |
| 预计影响时间 | 45 分钟 | 约 14:30 开始影响 |


### 5. 风险类型


包括：

#### 云层风险

例如：

```
未来60分钟云层接近
```

#### 辐射下降风险

例如：

```
预计辐射下降20%
```

#### 天气异常

例如：

- 强风
- 暴雨
- 高温


### 6. 预警记录


历史预警列表，每条包含：

- 等级图标
- 标题
- 等级徽章（含「解除预警」态）
- 发布时间
- 摘要说明
- 详情入口

## 六、站点 Site


### 1. 站点列表


标题「我的站点」，副标题「管理您的能源站点，实时掌握运行状态」。


类型筛选（带数量）：

```
全部（2）  光伏（1）  风电（1）
```

> 设计稿 `站点.png` 中含「上海储能站」示例与储能类型筛选项，**V1 不实现储能**。
> 该类型的卡片与指标不开发，筛选项不展示。


### 2. 添加站点

两条路：浏览公开目录，或自建。

- **公开目录**仍是主路径：全国近两万座光伏 / 风电场站的位置、容量、业主已有公开数据
  （[04 §七](./04-data-specification.md)），按月自动同步，选择即可查看，不复制个人副本。
- **自建电站**：目录里没有的电站自己添加，仅本账号可见。站点页顶部分「公开目录 / 我的电站」
  两段，我的电站段内有「添加电站」，「我的」页也有入口。每用户上限 10 座。

自建表单字段：名称、类型（光伏 / 风电）、装机容量（kW，交流侧）、经纬度、可选的出力模型
参数（倾角 / 方位角 / 轮毂高度）、可选的出力约束（[17 §四](./17-user-stations-and-outlook.md)）。

经纬度三种来源：

| 来源 | 坐标系 | 说明 |
| --- | --- | --- |
| 当前定位 | GCJ-02 | `wx.getLocation`，拒绝授权后仍可用其余两种 |
| 地图选点 | GCJ-02 | `wx.chooseLocation`，选到的地名可带入名称 |
| 手动输入 | 用户选择，默认 WGS84 | GPS 设备、谷歌地图读数选 WGS84；高德、腾讯、百度读数选 GCJ-02 |

提交时带 `coord`，服务端转成 WGS84 存储；客户端不做坐标转换。

此前「站点只从公开电站目录添加」的口径于 2026-09-12 撤销，原因与影响见
[17 §一](./17-user-stations-and-outlook.md)。


### 3. 站点管理

自建场站支持：

- 添加、编辑、删除。编辑与删除从列表「编辑」或详情页「编辑」进入表单；
  删除前二次确认，预警与发电记录一并删除
- 编辑全部字段：名称、类型、位置、装机容量、出力模型参数、出力约束
- 自建场站进入全部定时任务：发电累积、预警扫描、报告预生成、卫星归档；不进入全目录汇总

公开目录电站由平台维护，普通用户不能修改或删除。

类型：

- 光伏
- 风电

## 七、AI分析报告


入口：

首页快捷入口、地图 AI 提示条、站点详情快捷操作。


报告头部：

站点信息 + 报告日期 + 生成时间。


内容：

### 综合判断

例如：

```
今日适宜发电，
下午存在轻度云层风险。
```

附整体建议说明。


### 今日情况

按时间轴分析三段：

| 时段 | 时间区间 | 输出 |
| --- | --- | --- |
| 上午 | 06:00 – 12:00 | 天气概况 + 发电条件 |
| 下午 | 12:00 – 18:00 | 天气概况 + 发电条件 |
| 晚间 | 18:00 – 24:00 | 天气概况 + 对次日影响 |

时间轴节点按该时段风险等级配色。


### 风险提醒

展示当日主要风险及应对说明，可进入预警中心查看更多。


### 运营建议

编号列表输出，通常 3 条，每条为可执行动作。


### 数据摘要

四宫格，均带昨日环比：

```
发电量    等效利用小时    CO₂减排    收益预估
```

### 全目录历史趋势导航

首页仅保留“本站预测 / 全部场站”一层范围切换。全部场站顶部提供“历史趋势”
轻量入口，进入独立二级页面；历史页保留模型选择和周/月/年周期选择，返回后恢复
首页的全部场站范围。历史页不出现今日预测的刷新按钮或重复范围切换。

## 一、产品定位

EnerSight 是一个基于：

- 气象数据
- 卫星遥感数据
- 地理空间数据
- AI分析能力

的新型能源环境分析平台。


目标：

帮助用户快速了解某一区域：

- 当前新能源环境
- 未来气象变化
- 云层影响
- 发电风险

## 三、首页 Home


### 1. 站点定位与切换


顶部站点卡展示当前站点：

- 站点缩略图
- 站点名称 + 切换入口（下拉）
- 运行状态徽章
- 所在行政区 + 经纬度
- 进入站点详情的入口


支持：

#### 自动定位

通过设备 GPS：

获取：

- 当前经纬度
- 所在区域


#### 手动输入

支持：

- 城市搜索
- 地址搜索
- 经纬度输入


例如：

```
31.2304
120.5853
```


#### 站点切换

点击站点名称展开已建站点列表，切换后全页数据随之刷新。


---

### 2. 新能源环境指数


展示：

新能源环境指数。


示例：

```
新能源环境指数

92分

今日适宜发电，下午存在轻度云层影响
```


构成：

| 元素 | 说明 |
| --- | --- |
| 分数 | 0 – 100 分 |
| 等级 | 优秀 / 良好 / 一般 / 较差 |
| 一句话结论 | AI 生成，替代等级文字单独展示 |
| 说明入口 | 「?」图标，说明指数如何计算 |


影响因素：

- 太阳辐射
- 云量
- 温度
- 风速


---

### 3. 实时环境数据


四宫格展示：

| 指标 | 主值 | 辅助信息 |
| --- | --- | --- |
| 天气 | 32 ℃ | 天气现象文案（晴转多云） |
| 风速 | 4.5 m/s | 较昨日 ↑12% |
| 云量 | 35 % | 较昨日 ↓8% |
| 辐射 | 620 W/m² | 较昨日 ↑6% |


环比要求：

每项指标需与昨日同期对比，缺少昨日数据时隐藏环比标签。


> 湿度、风向不在首页四宫格展示，作为站点详情与 AI 分析的输入数据保留。


---

### 4. 气象趋势


支持：

- 24小时
- 7天


24 小时趋势：

- 指标切换：辐射（W/m²）/ 风速（m/s）/ 云量（%）
- 折线 + 面积图
- 点击数据点显示悬浮值（如 14:00 · 680 W/m²）并高亮该时刻
- 横轴 00:00 – 24:00
- 「查看更多」进入完整趋势页


---

### 5. 今日预警


首页展示当日最高等级的一条预警：

- 等级图标
- 预警标题
- 成因与影响说明
- 「查看更多」进入预警中心


无预警时：

卡片收起，不占据版面。

## 四、地图 Map


### 1. 顶部站点与搜索


- 左侧：当前站点选择器（缩略图 + 名称 + 下拉 + 所在区域）
- 右侧：搜索框，支持「搜索城市 / 坐标 / 站点」


### 2. 地图基础能力


提供：

- 全球地图
- 行政地图
- 卫星影像底图


支持：

- 缩放
- 拖动
- 定位
- 点击区域


### 3. 数据图层


右侧竖排图层切换器，同一时刻仅一个数据图层激活：

#### 云图

展示：

卫星云层。

#### 风场

展示：

风速和方向，以流线动画呈现。

#### 温度

展示：

区域温度。

#### 辐射

展示：

太阳辐射分布。

#### 站点

展示：

新能源站点，可与其他图层叠加。


> 图层的数据源、单位、值域、色阶与更新频率见
> [04 数据说明文档 · 四、地图图层数据规格](./04-data-specification.md#四地图图层数据规格)。


### 4. 地图控件


| 控件 | 位置 | 说明 |
| --- | --- | --- |
| 图层切换器 | 右上 | 竖排 5 项，激活项蓝底白字 |
| 定位按钮 | 右中 | 回到当前站点 |
| 缩放按钮 | 右中 | + / − |
| 图例 | 左下 | 随激活图层切换，展示单位与色阶刻度 |
| 比例尺 | 右下 | 随缩放级别变化 |
| 当前位置标记 | 地图内 | 蓝色定位点 + 名称气泡 |


### 5. 底部站点面板


可上下拖拽的面板，展示当前站点摘要：

- 站点名称 + 运行状态 + 进入详情入口
- 所在行政区 + 经纬度
- 四宫格：新能源指数 / 天气（含体感温度）/ 风速 / 辐射
- AI 提示条：一句话结论，点击进入 AI 分析报告

## 五、预警 Alert


功能：

监测新能源风险。


### 1. 页面结构

标题「预警中心」，副标题「实时监测 · 精准预警 · 助力稳定发电」。


### 2. 等级筛选

```
全部    轻度    中度    重度
```

轻/中/重分别以绿、橙、红状态点标识。


### 3. 卫星云图

- 左上角：数据类型 + 观测时间（如 2024-07-20 14:00）
- 地图内：站点位置标记
- 右下角：云量强度图例（低 — 高）
- 右上角：全屏查看


### 4. 当前预警


卡片包含：

- 风险等级徽章
- 发布时间
- 预警标题
- 成因与影响说明


云团外推三宫格：

| 项 | 示例 | 辅助说明 |
| --- | --- | --- |
| 云团距离 | 80 km | 距苏州光伏站 |
| 移动方向 | 东北 | 向东 / 东北方向移动 |
| 预计影响时间 | 45 分钟 | 约 14:30 开始影响 |


### 5. 风险类型


包括：

#### 云层风险

例如：

```
未来60分钟云层接近
```

#### 辐射下降风险

例如：

```
预计辐射下降20%
```

#### 天气异常

例如：

- 强风
- 暴雨
- 高温


### 6. 预警记录


历史预警列表，每条包含：

- 等级图标
- 标题
- 等级徽章（含「解除预警」态）
- 发布时间
- 摘要说明
- 详情入口

### 1. 站点列表


标题「我的站点」，副标题「管理您的能源站点，实时掌握运行状态」。


类型筛选（带数量）：

```
全部（2）  光伏（1）  风电（1）
```

### 2. 添加站点


顶部添加卡提供两种录入方式：

| 方式 | 说明 |
| --- | --- |

| 输入经纬度 | 手动输入站点坐标信息 |

### 3. 站点管理


支持：

- 新增站点
- 删除站点
- 编辑站点
- 分类管理

删除与编辑通过卡片右上角「⋯」菜单进入。


类型：

- 光伏
- 风电


### 4. 站点卡片


展示：

- 站点图片
- 名称 + 装机容量
- 运行状态徽章
- 所在行政区 + 经纬度
- 四项运行指标


指标（光伏与风电共用一套）：

```
今日发电    实时功率    累计发电    减排量
```


### 5. 站点详情


展示：

| 模块 | 内容 |
| --- | --- |
| 站点信息 | 图片、名称、状态、地址、类型、装机容量 |
| 当前天气 | 四宫格 + 数据更新时间 |
| 环境指数 | 新能源环境指数卡 |
| 趋势分析 | 24 小时趋势（辐射 / 风速 / 云量） |
| 快捷操作 | 卫星云图、AI分析报告 |

## 七、AI分析报告


入口：

首页快捷入口、地图 AI 提示条、站点详情快捷操作。


报告头部：

站点信息 + 报告日期 + 生成时间。


内容：

### 综合判断

例如：

```
今日适宜发电，
下午存在轻度云层风险。
```

附整体建议说明。


### 今日情况

按时间轴分析三段：

| 时段 | 时间区间 | 输出 |
| --- | --- | --- |
| 上午 | 06:00 – 12:00 | 天气概况 + 发电条件 |
| 下午 | 12:00 – 18:00 | 天气概况 + 发电条件 |
| 晚间 | 18:00 – 24:00 | 天气概况 + 对次日影响 |

时间轴节点按该时段风险等级配色。


### 风险提醒

展示当日主要风险及应对说明，可进入预警中心查看更多。


### 运营建议

编号列表输出，通常 3 条，每条为可执行动作。


### 数据摘要

四宫格，均带昨日环比：

```
发电量    等效利用小时    CO₂减排    收益预估
```

> EnerSight AI 新能源气象遥感分析平台 · 文档包 V1.0
>
> 本文档定义所有派生指标的计算口径。
> 原始数据字段见 [04 数据说明文档](./04-data-specification.md)。
>
> ⚠️ 本文档中的权重、基准值、系数均为**建议初值**，全部可配置。

## 一、新能源环境指数


产品中最核心的派生指标，首页、地图底部面板、站点详情、AI 报告都在用。
在此之前全套文档没有定义它怎么算 —— 本章补上。


### 1.1 总体结构

```
四个因子分别归一化为 0-100 分

↓ 按站点类型加权

总分 0-100

↓ 分档

优秀 / 良好 / 一般 / 较差
```


### 1.2 计算周期

指数按**当日**计算，不是瞬时值。


理由：

产品语义是「今日适宜发电」，用户全天看到的应是同一个分数，
用瞬时辐射会导致傍晚分数暴跌，与文案矛盾。


输入取当日预测的日间聚合值：

| 因子 | 取值 |
| --- | --- |
| 辐射 | 当日累计短波辐射（kWh/m²） |
| 云量 | 日间时段平均云量 |
| 温度 | 日间时段平均气温 |
| 风速 | 日间时段平均风速 |

刷新时机：每日 00:00 生成，气象预报更新后（每 1 小时）重算。


#### 日间时段的定义

**日间时段不是固定的 06:00–18:00，按站点经纬度与日期计算日出日落。**

固定时段在高纬度和冬季会严重失真：漠河冬至日照不足 7 小时，
用 06:00–18:00 求平均会把 5 小时的夜间数据算进「日间云量」。

```
日间时段 = [日出时刻, 日落时刻]
```

计算见 [附录 A · 太阳位置计算](#附录-a太阳位置计算)。

风电站是例外：风力发电不分昼夜，**风电站的所有因子取全天 24 小时平均**，
不使用日间窗口。


> 注意区分两个时间概念：
> 本节的**日间时段**是指标聚合窗口，按日出日落动态计算；
> AI 报告的**上午 / 下午 / 晚间**（06–12 / 12–18 / 18–24）是面向用户的固定展示分段，
> 与设计稿一致，不随日出日落变化。两者用途不同，不要混用。

### 1.3 因子评分函数


#### 辐射评分 S_rad

基准值不是固定常数，而是**当日当地的晴空理论辐射**。

```
Kt = E_day / E_clear          晴空指数

S_rad = min(100, Kt / Kt_ref × 100)

E_day   = 当日累计实际辐射（kWh/m²），来自气象预报
E_clear = 当日累计晴空理论辐射（kWh/m²），由经纬度与日期算出
Kt_ref  = 0.75    满分对应的晴空指数，可配置
```

用固定基准（如 6.0 kWh/m²）的问题：高纬度站点和冬季永远拿低分，
但冬天的大晴天对电站运维而言就是好天气。晴空指数自动适配纬度与季节。

`E_clear` 计算见 [附录 A](#附录-a太阳位置计算)。


#### 云量评分 S_cloud

```
S_cloud = 100 - C_avg

C_avg = 日间平均总云量（%）
```


#### 温度评分 S_temp

光伏组件在 25℃ 附近效率最高，偏离即降效。

```
S_temp = max(0, 100 - |T_avg - 25| × 2)
```

| T_avg | S_temp |
| --- | --- |
| 25℃ | 100 |
| 32℃ | 86 |
| 40℃ | 70 |
| 5℃ | 60 |


#### 风速评分 S_wind

光伏与风电的风速偏好完全相反，必须分开定义。

**光伏**（微风利于散热，大风是风险）：

```
v < 2         S = 60 + v × 20
2 ≤ v ≤ 6     S = 100
6 < v < 15    S = 100 - (v - 6) × 5
v ≥ 15        S = 0
```

**风电**（对标典型机组功率曲线）：

```
v < 3         S = 0            切入风速以下
3 ≤ v < 12    S = (v³ - 27) / (12³ - 27) × 100
12 ≤ v ≤ 25   S = 100          额定区间
v > 25        S = 0            切出风速
```

### 1.4 因子权重


| 因子 | 光伏 | 风电 | 区域通用 |
| --- | --- | --- | --- |
| 辐射 | 50% | 0% | 40% |
| 云量 | 25% | 0% | 25% |
| 温度 | 15% | 10% | 15% |
| 风速 | 10% | 90% | 20% |


```
指数 = Σ (因子分 × 权重)
```

「区域通用」用于地图页按区域展示、以及站点类型未知的场景。


> 风电站的辐射与云量权重为 0，因此风电站的指数实质由风速主导。

### 1.6 样例验算


用设计稿「苏州光伏站」的数据代入（31.30°N，120.62°E，8月20日）。


第一步，算当日晴空基准：

```
太阳赤纬  δ = 11.75°
日长      12.97 h        日出 05:32，日落 18:29
峰值高度角 h_max = 70.45°
峰值晴空辐射 = 1361 × sin(70.45°) × 0.75 = 962 W/m²
晴空日累计 E_clear = 962 × 12.97 × 2/π = 7.94 kWh/m²
```


第二步，代入实测：

```
辐射 620 W/m²（14:00 瞬时）→ 当日累计约 5.1 kWh/m²
云量 35%
气温 32℃
风速 4.5 m/s

晴空指数 Kt = 5.1 / 7.94 = 0.64
```


因子得分：

| 因子 | 计算 | 得分 | 权重 | 加权 |
| --- | --- | --- | --- | --- |
| 辐射 | 0.64 / 0.75 × 100 | 85.6 | 50% | 42.8 |
| 云量 | 100 − 35 | 65 | 25% | 16.3 |
| 温度 | 100 − \|32−25\| × 2 | 86 | 15% | 12.9 |
| 风速 | 4.5 落在 2–6 区间 | 100 | 10% | 10.0 |

```
总分 = 82.0  →  82 分  「良好」
```


> ⚠️ **设计稿的 92 分在给定输入下数学上不可达。**
>
> 固定云量 35%（云量分 65）、气温 32℃、风速 4.5 m/s，即使**辐射拿满分 100**：
>
> ```
> 上限 = 100×0.50 + 65×0.25 + 86×0.15 + 100×0.10 = 89.2 分
> ```
>
> 92 分要求云量 ≤ 23.6% 且辐射接近满分。
> 也就是说设计稿标注的**输入数据与输出分数本身不自洽**，不是算法调参能解决的。
>
> 两个方向，需产品决策：
> ① 改设计稿示例数据（云量调到 20% 以下，与 92 分匹配）；
> ② 保留设计稿，接受真实数据下这天就是 82 分「良好」。
>
> 建议 ② —— 35% 云量的天本来就不该是「优秀」。

## 二、发电量估算


V1 站点无实测数据，全部由气象数据推算。
接入实测后本章公式仅用于「预测值」，实测优先。


### 2.1 光伏

```
T_cell = T_air + (NOCT − 20) / 800 × GTI

P(t) = C × (GTI(t) / 1000) × PR × [1 − γ × (T_cell − 25)]

E_day = Σ P(t) × 1h        逐小时求和
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `C` | 装机容量（kW） | 站点配置 |
| `GTI` | 倾斜面总辐射（W/m²） | Open-Meteo |
| `PR` | 系统性能比 | 0.80 |
| `γ` | 功率温度系数（/℃） | 0.004 |
| `NOCT` | 标称工作温度（℃） | 45 |


样例（500 kW，GTI 620 W/m²，气温 32℃）：

```
T_cell = 32 + 25/800 × 620 = 51.4℃
P = 500 × 0.62 × 0.80 × [1 − 0.004 × 26.4]
  = 248 × 0.894
  = 222 kW
```

> ⚠️ 设计稿标注实时功率 **320 kW**。320 / 500 = 0.64 ≈ GTI/1000，
> 说明设计稿是直接用「装机 × 辐射比」，未计入 PR 与温度损失。
> 本文档的公式更接近真实出力，两者差约 30%。


### 2.2 风电

典型机组功率曲线：

```
v < 3  或  v > 25        P = 0

3 ≤ v < 12               P = C × (v³ − 3³) / (12³ − 3³)

12 ≤ v ≤ 25              P = C
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `v_in` | 切入风速（m/s） | 3 |
| `v_rated` | 额定风速（m/s） | 12 |
| `v_out` | 切出风速（m/s） | 25 |

风速取轮毂高度值；Open-Meteo 提供 10m 风速时按幂律外推：

```
v_hub = v_10 × (h_hub / 10) ^ 0.14
```


### 2.3 等效利用小时

```
h_eq = E_day / C
```

单位统一后相除（kWh ÷ kW = h）。

## 三、衍生指标


### 3.1 CO₂ 减排量

```
CO₂(吨) = E(kWh) × f / 1000

f = 0.8 kg CO₂/kWh      全国电网平均排放因子，可配置
```

与设计稿一致：累计发电 1.26 GWh → 1,008 吨 ✓


### 3.2 收益预估

```
R(元) = E(kWh) × p

p = 0.4 元/kWh          站点配置的上网电价，默认值
```

与设计稿一致：6,320 kWh × 0.4 = 2,528 元 ✓

> 分时电价、市场化交易电价属于后续扩展，V1 用站点级固定电价。


### 3.3 环比

```
Δ% = (今值 − 昨值) / 昨值 × 100%
```

规则：

- 对比昨日**同期**（同一时刻或同一日累计口径），不是昨日全天
- 昨值缺失或为 0 时隐藏环比标签，不展示 0% 或 ∞
- 展示保留整数百分比
- 上升红色、下降绿色（表示变化方向，非好坏，见设计规范）

## 四、短临云层外推


### 4.1 云团移动

对相邻两帧卫星云图做位移估计，得到移动矢量 `(dx, dy)`。

```
v_cloud = √(dx² + dy²) / Δt        Δt = 10 分钟
θ = atan2(dx, dy)                  换算为 16 方位文案
```


### 4.2 影响时间

```
t_impact(分钟) = d / v_cloud × 60

d = 云团前沿到站点的距离（km）
v_cloud = 移动速度（km/h）
```

设计稿样例：80 km ÷ 107 km/h ≈ 45 分钟 ✓


约束：

- 外推时效上限 120 分钟，超出不出预警
- 云团移动方向偏离站点超过 ±45° 时不出预警


### 4.3 辐射降幅

```
drop% = (GHI_clear − GHI_forecast) / GHI_clear × 100%

GHI_clear = 晴空理论辐射
```

```
GHI_clear = 1361 × sin(h_sun) × τ

h_sun = 该时刻的太阳高度角
```

太阳高度角与 τ 见 [附录 A](#附录-a太阳位置计算)，与环境指数共用同一份实现。

## 五、预警触发规则


### 5.1 云层 / 辐射风险

| 预计辐射降幅 | 等级 |
| --- | --- |
| < 20% | 轻度 |
| 20% – 40% | 中度 |
| > 40% | 重度 |

低于 10% 不触发预警。


### 5.2 天气异常

| 类型 | 触发条件 | 等级 |
| --- | --- | --- |
| 强风 | 风速 > 15 m/s | 中度 |
| 强风 | 风速 > 25 m/s（风机切出） | 重度 |
| 暴雨 | `weather_code` 命中暴雨类 | 中度 |
| 高温 | 气温 > 38℃ | 中度 |
| 低温 | 气温 < −10℃ | 中度 |


### 5.3 解除预警

原预警条件不再满足，且持续 30 分钟稳定，生成一条「解除预警」记录。


### 5.4 去重

同一站点同一类型的预警，2 小时内不重复推送，仅更新已有记录。

## 六、数据缺失降级


| 缺失项 | 降级策略 |
| --- | --- |
| 单个气象因子 | 该因子按权重剔除，其余权重等比放大，指数照常计算 |
| 全部气象数据 | 指数不展示，卡片显示「数据获取中」 |
| 卫星云图 | 短临预警停用，气象预报类预警照常 |
| 昨日数据 | 隐藏所有环比标签 |
| 站点装机容量未填 | 不展示发电量、等效小时、收益预估 |

## 附录 A·太阳位置计算


用于确定日间时段与晴空辐射基准。实现放在 `packages/core/metrics/solar.ts`，
前后端共用同一份。


### A.1 太阳赤纬

```
n = 日序数（1 – 365/366）

δ = 23.45° × sin(360° × (284 + n) / 365)
```


### A.2 日长与日出日落

```
φ = 站点纬度

时角  ω_s = arccos(−tan φ × tan δ)

日长 = 2 × ω_s / 15          小时

日出（太阳时） = 12 − ω_s / 15
日落（太阳时） = 12 + ω_s / 15
```


极昼极夜处理：

```
−tan φ × tan δ > 1    →  极夜，日长 = 0
−tan φ × tan δ < −1   →  极昼，日长 = 24
```

境内站点不会触发，但海外扩展时必须处理，否则 `arccos` 定义域越界。


### A.3 转换为本地钟表时间

```
钟表时 = 太阳时 − (经度 − 时区中央经线) × 4分钟 − EoT

EoT = 均时差（分钟）
B = 360° × (n − 81) / 364
EoT = 9.87 sin(2B) − 7.53 cos(B) − 1.5 sin(B)
```

中国全境用 UTC+8，中央经线 120°E。


### A.4 晴空日累计辐射

```
峰值太阳高度角  h_max = 90° − |φ − δ|

峰值晴空辐射   G_peak = 1361 × sin(h_max) × τ

晴空日累计     E_clear = G_peak × 日长 × 2/π
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `1361` | 太阳常数（W/m²） | 固定 |
| `τ` | 大气透射率 | 0.75 |
| `2/π` | 正弦半波日积分系数 | 0.6366 |


### A.5 精度

简化公式的日出日落误差约 ±2 分钟，晴空辐射误差约 ±5%。

对本产品足够 —— 它只用于确定聚合窗口和评分基准，不是天文计算。
若后续需要更高精度，改用 NOAA Solar Calculator 算法或引入 `suncalc` 库，
接口保持不变。


### A.6 使用位置

| 用途 | 说明 |
| --- | --- |
| 日间时段 | 云量 / 温度 / 风速的聚合窗口（风电除外，用全天） |
| 晴空基准 | 辐射评分 `S_rad` 的分母 |
| 辐射降幅 | 预警的 `GHI_clear` 基线，见 §4.3 |
| 卫星云图 | 判断可见光/红外自动切换的昼夜边界，见 04 文档 |

# 07 指标计算规则 · Metrics

> EnerSight AI 新能源气象遥感分析平台 · 文档包 V1.0
>
> 本文档定义所有派生指标的计算口径。
> 原始数据字段见 [04 数据说明文档](./04-data-specification.md)。
>
> ⚠️ 本文档中的权重、基准值、系数均为**建议初值**，全部可配置。
> 落地前需产品确认，确认后此处即为唯一口径，前后端与 AI 提示词都引用本文档。


## 一、新能源环境指数


产品中最核心的派生指标，首页、地图底部面板、站点详情、AI 报告都在用。
在此之前全套文档没有定义它怎么算 —— 本章补上。


### 1.1 总体结构

```
四个因子分别归一化为 0-100 分

↓ 按站点类型加权

总分 0-100

↓ 分档

优秀 / 良好 / 一般 / 较差
```


### 1.2 计算周期

指数按**当日**计算，不是瞬时值。


理由：

产品语义是「今日适宜发电」，用户全天看到的应是同一个分数，
用瞬时辐射会导致傍晚分数暴跌，与文案矛盾。


输入取当日预测的日间聚合值：

| 因子 | 取值 |
| --- | --- |
| 辐射 | 当日累计短波辐射（kWh/m²） |
| 云量 | 日间时段（06:00–18:00）平均云量 |
| 温度 | 日间时段平均气温 |
| 风速 | 日间时段平均风速 |

刷新时机：每日 00:00 生成，气象预报更新后（每 1 小时）重算。


---

### 1.3 因子评分函数


#### 辐射评分 S_rad

```
S_rad = min(100, E_day / E_ref × 100)

E_day = 当日累计辐射（kWh/m²）
E_ref = 6.0 kWh/m²   基准值，可按站点纬度配置
```


#### 云量评分 S_cloud

```
S_cloud = 100 - C_avg

C_avg = 日间平均总云量（%）
```


#### 温度评分 S_temp

光伏组件在 25℃ 附近效率最高，偏离即降效。

```
S_temp = max(0, 100 - |T_avg - 25| × 2)
```

| T_avg | S_temp |
| --- | --- |
| 25℃ | 100 |
| 32℃ | 86 |
| 40℃ | 70 |
| 5℃ | 60 |


#### 风速评分 S_wind

光伏与风电的风速偏好完全相反，必须分开定义。

**光伏**（微风利于散热，大风是风险）：

```
v < 2         S = 60 + v × 20
2 ≤ v ≤ 6     S = 100
6 < v < 15    S = 100 - (v - 6) × 5
v ≥ 15        S = 0
```

**风电**（对标典型机组功率曲线）：

```
v < 3         S = 0            切入风速以下
3 ≤ v < 12    S = (v³ - 27) / (12³ - 27) × 100
12 ≤ v ≤ 25   S = 100          额定区间
v > 25        S = 0            切出风速
```


---

### 1.4 因子权重


| 因子 | 光伏 | 风电 | 区域通用 |
| --- | --- | --- | --- |
| 辐射 | 50% | 0% | 40% |
| 云量 | 25% | 0% | 25% |
| 温度 | 15% | 10% | 15% |
| 风速 | 10% | 90% | 20% |


```
指数 = Σ (因子分 × 权重)
```

「区域通用」用于地图页按区域展示、以及站点类型未知的场景。


> **储能站待产品确认。** 储能不发电，「新能源环境指数」对它没有直接语义。
> 三个可选方案：① 不展示该指数，改展示 SOC 与充放电状态；
> ② 展示所在区域的通用指数；③ 定义为「调峰机会指数」（区域出力波动越大分越高）。
> 建议 V1 选 ①。


---

### 1.5 分档阈值

| 分数 | 等级 | 颜色 |
| --- | --- | --- |
| ≥ 85 | 优秀 | Energy Green |
| 70 – 84 | 良好 | Energy Green |
| 55 – 69 | 一般 | Warning Orange |
| < 55 | 较差 | Danger Red |


---

### 1.6 样例验算


用设计稿「苏州光伏站」的数据代入。


输入：

```
辐射 620 W/m²（瞬时）→ 当日累计约 5.0 kWh/m²
云量 35%
气温 32℃
风速 4.5 m/s
```


因子得分：

| 因子 | 计算 | 得分 | 权重 | 加权 |
| --- | --- | --- | --- | --- |
| 辐射 | 5.0 / 6.0 × 100 | 83 | 50% | 41.5 |
| 云量 | 100 − 35 | 65 | 25% | 16.3 |
| 温度 | 100 − \|32−25\| × 2 | 86 | 15% | 12.9 |
| 风速 | 4.5 落在 2–6 区间 | 100 | 10% | 10.0 |

```
总分 = 80.7  →  81 分  「良好」
```


> ⚠️ **与设计稿不一致。** 设计稿标注 **92 分**，本算法算出 **81 分**。
>
> 两种可能：设计稿的 92 分是视觉示意值，不必对齐；或者基准值定得偏严
> （把 `E_ref` 从 6.0 降到 5.2 可得约 89 分）。
>
> 这需要产品决策，不应由实现方私自调参去凑设计稿的数字。

## 二、发电量估算


V1 站点无实测数据，全部由气象数据推算。
接入实测后本章公式仅用于「预测值」，实测优先。


### 2.1 光伏

```
T_cell = T_air + (NOCT − 20) / 800 × GTI

P(t) = C × (GTI(t) / 1000) × PR × [1 − γ × (T_cell − 25)]

E_day = Σ P(t) × 1h        逐小时求和
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `C` | 装机容量（kW） | 站点配置 |
| `GTI` | 倾斜面总辐射（W/m²） | Open-Meteo |
| `PR` | 系统性能比 | 0.80 |
| `γ` | 功率温度系数（/℃） | 0.004 |
| `NOCT` | 标称工作温度（℃） | 45 |


样例（500 kW，GTI 620 W/m²，气温 32℃）：

```
T_cell = 32 + 25/800 × 620 = 51.4℃
P = 500 × 0.62 × 0.80 × [1 − 0.004 × 26.4]
  = 248 × 0.894
  = 222 kW
```

> ⚠️ 设计稿标注实时功率 **320 kW**。320 / 500 = 0.64 ≈ GTI/1000，
> 说明设计稿是直接用「装机 × 辐射比」，未计入 PR 与温度损失。
> 本文档的公式更接近真实出力，两者差约 30%。


### 2.2 风电

典型机组功率曲线：

```
v < 3  或  v > 25        P = 0

3 ≤ v < 12               P = C × (v³ − 3³) / (12³ − 3³)

12 ≤ v ≤ 25              P = C
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `v_in` | 切入风速（m/s） | 3 |
| `v_rated` | 额定风速（m/s） | 12 |
| `v_out` | 切出风速（m/s） | 25 |

风速取轮毂高度值；Open-Meteo 提供 10m 风速时按幂律外推：

```
v_hub = v_10 × (h_hub / 10) ^ 0.14
```


### 2.3 等效利用小时

```
h_eq = E_day / C
```

单位统一后相除（kWh ÷ kW = h）。

## 三、衍生指标


### 3.1 CO₂ 减排量

```
CO₂(吨) = E(kWh) × f / 1000

f = 0.8 kg CO₂/kWh      全国电网平均排放因子，可配置
```

与设计稿一致：累计发电 1.26 GWh → 1,008 吨 ✓


### 3.2 收益预估

```
R(元) = E(kWh) × p

p = 0.4 元/kWh          站点配置的上网电价，默认值
```

与设计稿一致：6,320 kWh × 0.4 = 2,528 元 ✓

> 分时电价、市场化交易电价属于后续扩展，V1 用站点级固定电价。


### 3.3 环比

```
Δ% = (今值 − 昨值) / 昨值 × 100%
```

规则：

- 对比昨日**同期**（同一时刻或同一日累计口径），不是昨日全天
- 昨值缺失或为 0 时隐藏环比标签，不展示 0% 或 ∞
- 展示保留整数百分比
- 上升红色、下降绿色（表示变化方向，非好坏，见设计规范）

## 四、短临云层外推


### 4.1 云团移动

对相邻两帧卫星云图做位移估计，得到移动矢量 `(dx, dy)`。

```
v_cloud = √(dx² + dy²) / Δt        Δt = 10 分钟
θ = atan2(dx, dy)                  换算为 16 方位文案
```


### 4.2 影响时间

```
t_impact(分钟) = d / v_cloud × 60

d = 云团前沿到站点的距离（km）
v_cloud = 移动速度（km/h）
```

设计稿样例：80 km ÷ 107 km/h ≈ 45 分钟 ✓


约束：

- 外推时效上限 120 分钟，超出不出预警
- 云团移动方向偏离站点超过 ±45° 时不出预警


### 4.3 辐射降幅

```
drop% = (GHI_clear − GHI_forecast) / GHI_clear × 100%

GHI_clear = 晴空理论辐射
```

晴空辐射简化估算：

```
GHI_clear = 1361 × sin(h_sun) × 0.75

h_sun = 太阳高度角，由经纬度与时刻计算
```

## 五、预警触发规则


### 5.1 云层 / 辐射风险

| 预计辐射降幅 | 等级 |
| --- | --- |
| < 20% | 轻度 |
| 20% – 40% | 中度 |
| > 40% | 重度 |

低于 10% 不触发预警。


### 5.2 天气异常

| 类型 | 触发条件 | 等级 |
| --- | --- | --- |
| 强风 | 风速 > 15 m/s | 中度 |
| 强风 | 风速 > 25 m/s（风机切出） | 重度 |
| 暴雨 | `weather_code` 命中暴雨类 | 中度 |
| 高温 | 气温 > 38℃ | 中度 |
| 低温 | 气温 < −10℃ | 中度 |


### 5.3 解除预警

原预警条件不再满足，且持续 30 分钟稳定，生成一条「解除预警」记录。


### 5.4 去重

同一站点同一类型的预警，2 小时内不重复推送，仅更新已有记录。

## 六、数据缺失降级


| 缺失项 | 降级策略 |
| --- | --- |
| 单个气象因子 | 该因子按权重剔除，其余权重等比放大，指数照常计算 |
| 全部气象数据 | 指数不展示，卡片显示「数据获取中」 |
| 卫星云图 | 短临预警停用，气象预报类预警照常 |
| 昨日数据 | 隐藏所有环比标签 |
| 站点装机容量未填 | 不展示发电量、等效小时、收益预估 |

## 七、参数配置清单


以下参数需可在服务端配置，不硬编码：

| 参数 | 默认值 | 影响 |
| --- | --- | --- |
| `E_ref` 辐射基准 | 6.0 kWh/m² | 环境指数 |
| 因子权重（三套） | 见 1.4 | 环境指数 |
| 分档阈值 | 85 / 70 / 55 | 环境指数等级 |
| `PR` 系统性能比 | 0.80 | 光伏发电估算 |
| `γ` 温度系数 | 0.004 /℃ | 光伏发电估算 |
| `NOCT` | 45℃ | 光伏发电估算 |
| `v_in` / `v_rated` / `v_out` | 3 / 12 / 25 m/s | 风电发电估算 |
| `f` 碳排放因子 | 0.8 kg/kWh | CO₂ 减排 |
| `p` 上网电价 | 0.4 元/kWh | 收益预估 |
| 预警降幅阈值 | 20% / 40% | 预警等级 |
| 外推时效上限 | 120 分钟 | 短临预警 |

核对设计稿时发现的数值矛盾，需产品确认后统一：

| # | 问题 | 位置 | 说明 |
| --- | --- | --- | --- |
| 1 | 环境指数 92 分算不出来 | 首页、地图、站点详情 | 本文档算法得 81 分，见 1.6 |
| 2 | 同一站点发电量差 2.6 倍 | 站点.png vs 站点3.png | 站点卡 2,400 kWh（500 kW → 4.8h）；AI 报告 6,320 kWh / 4.5h（反推 1,404 kW）。同为「苏州光伏站」 |
| 3 | 实时功率未计损失 | 站点.png | 320 kW ≈ 装机 × 辐射比，未含 PR 与温度损失，见 2.1 |
| 4 | 光伏与风电等效小时相同 | 站点.png | 光伏 2400/500 = 4.8h，风电 9600/2000 = 4.8h，应为套用的示意值 |

> 1、3、4 判断为设计稿使用了示意数值，不影响实现；

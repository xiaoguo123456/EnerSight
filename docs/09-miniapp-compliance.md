# 09 小程序合规清单 · Compliance

> EnerSight AI 新能源气象遥感分析平台 · 文档包 V1.0
>
> ⚠️ **本文档是技术侧的准备清单，不是法律意见。**
> 微信平台规则与监管要求变动频繁，文中的周期、材料、条款均需在办理前
> 到微信开放社区与主管部门核对最新口径，涉及备案与资质的结论请法务确认。
>
> 合规是唯一可能让代码全部写完却发不出去的东西，因此**前置项要与开发并行启动**，
> 不要等功能做完再办。


## 一、为什么这份文档要早读


本项目触碰了三个高门槛能力：

| 能力 | 门槛 |
| --- | --- |
| 地理位置 | 需申请接口权限，人工审核，说明写不好会被驳回 |
| 服务器请求 | 域名必须 ICP 备案，备案周期以周计 |
| AI 生成内容 | 涉及生成式 AI 服务管理要求，且内容需过安全检测 |

三项都不是「提审前一天补一下」能解决的。见 [§九 时间线](#九时间线与前置依赖)。

## 二、主体与类目


### 2.1 主体类型

**建议企业主体，不要用个人主体。**

| 项 | 个人主体 | 企业主体 |
| --- | --- | --- |
| 可选服务类目 | 少 | 多 |
| `web-view` 组件 | 不可用 | 可用 |
| 部分高级接口 | 受限 | 可申请 |
| 微信支付 | 不可用 | 可用 |

本项目 V1 虽未用 `web-view`，但地图能力若 spike 失败需降级到 H5 内嵌
（见 [05 §6.7](./05-architecture.md)），个人主体会直接堵死这条退路。


### 2.2 服务类目

类目决定能申请哪些接口，需与实际功能一致，否则审核驳回。

本项目功能对应的方向：工具类 / 信息查询 / 商业服务（能源）。

> 待办：到 mp 后台「设置 → 基本设置 → 服务类目」核对当前可选类目树，
> 确认「地理位置」接口在所选类目下可申请。类目一旦选定变更需重新审核。

## 三、备案


小程序备案与域名 ICP 备案是**两件独立的事**，都要办。


### 3.1 小程序备案

新上架小程序必须先完成备案才能提交审核发布。

| 项 | 说明 |
| --- | --- |
| 入口 | mp 后台「设置 → 基本设置 → 备案」 |
| 材料 | 主体资质、负责人身份信息、功能说明 |
| 周期 | 微信初审 + 管局审核，通常以工作日计，各省差异大 |
| 风险 | 功能说明与实际不符会被退回重填 |


### 3.2 服务器域名 ICP 备案

BFF 域名（`api.enersight.example.com`）必须完成 ICP 备案。

- 服务器需在**境内**，境外服务器无法备案
- 备案主体应与小程序主体一致，否则需授权材料
- 未备案域名无法配置为小程序合法域名，请求直接失败

> 这条决定了 [05 §八](./05-architecture.md) 的部署位置，不是可选项。

## 四、隐私协议与用户授权


### 4.1 隐私保护指引

需在 mp 后台配置《小程序用户隐私保护指引》，声明收集的信息类型。

本项目至少需声明：

| 信息类型 | 用途 |
| --- | --- |
| 位置信息 | 自动定位当前区域、获取站点经纬度 |
| 设备信息 | 服务运行与故障排查 |
| 用户填写的站点信息 | 站点管理与数据分析 |

未配置或声明不全，相关接口调用会失败。


### 4.2 授权弹窗

首次调用涉及隐私的接口前需触发授权流程，用户拒绝后要有可用的降级路径。

**降级要求**：拒绝定位授权时，产品必须仍然可用 ——
引导用户手动搜索城市或输入经纬度（[01 §三](./01-prd.md) 已定义手动输入路径）。

不要做成「不给定位就白屏」。


### 4.3 登录口径

依据《微信小程序平台运营规范》15.1.3（用户未触发功能时不得提前弹窗申请权限、拒绝授权后不得停止全部服务）
与 12.6（存在账号体系须提供微信授权登录、拒绝后不得反复提醒、须有退出）。

- **游客模式。** 进入小程序不登录、不弹任何授权。公开电站、地图、云图、预警、报告与全目录预测游客可看，
  对应接口允许不带令牌。
- **需要登录的操作。** 我的电站（列表、添加、编辑、删除，以及查看自建电站的预测、预警、报告）与 CSV 导出。
  未登录时进入登录页；服务端对游客访问自建电站返回 `401 LOGIN_REQUIRED`。
- **登录页。** 「微信一键登录」：`wx.login` → 服务端 `code2session` → 签发令牌。《用户服务协议》《隐私保护指引》
  勾选框默认不勾选，未勾选点登录先弹窗请用户同意；提供「暂不登录」返回原页面。
- **续登。** 主动登录过的用户令牌失效时后台静默续登并重试一次，并发请求共用一次续登；游客不自动登录。
- **退出与删除。** 「我的」页提供「退出登录」与「删除我的数据」（`DELETE /v1/me`：全部自建电站及其预警、发电记录、
  报告与预测留档，不可恢复）。退出或删除后，本机记住的自建电站从当前电站、收藏与最近浏览中移除。
- **只用 openid 区分账号。** 「我的」页登录后只显示「微信用户」，不铺登录说明文字。
- 《用户服务协议》正文在小程序「我的 → 数据与隐私」内，为产品草稿，上线前须法务审核。
- **不采集手机号、头像与昵称。** 自建场站只需要稳定的账号标识，这些信息功能上用不到：
  手机号快速验证仅对非个人主体开放、超出免费额度按次收费，还要在隐私保护指引中增加用途声明；
  头像昵称只能由用户在 `chooseAvatar` 按钮或 `type="nickname"` 输入框中主动填写，无法静默获取。
- 以后若需要跨设备找回数据或联系用户，再在具体功能入口按需申请，不做成进入小程序的门槛。


### 4.4 隐私保护指引填写清单

在 mp 后台「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」中填写（后台入口以当前版本为准），由运营主体提交：

| 勾选的信息类型 | 触发的接口 | 用途（原样填写） |
| --- | --- | --- |
| 位置信息 | `wx.getLocation` | 用户添加或编辑自建电站时点击「当前定位」，获取一次当前位置填入电站坐标 |
| 选中的位置信息 | `wx.chooseLocation` | 用户添加或编辑自建电站时点击「地图选点」，在地图上选择电站位置 |

- 小程序未使用手机号、头像昵称、相册写入、剪贴板读取、摄像头、麦克风、蓝牙等隐私接口，不要勾选。
  复制链接用的 `wx.setClipboardData` 只写入剪贴板，文件消息 `wx.shareFileMessage` 由用户选择会话，均不在隐私接口清单内。
- 「开发者收集的信息」补充：用户填写的自建电站信息（名称、类型、坐标、装机容量、设备参数、限电规则），
  用于该电站的气象预测、预警、分析报告与卫星影像归档，仅本账号可见；用户可删除单个电站或删除全部数据。
- 存储期限、运营者联系方式按主体实际情况填写。
- 未自定义隐私弹窗：调用上述接口时由微信弹出官方授权弹窗；用户拒绝后仍可手动输入经纬度，不反复弹窗。
- 地图页不显示用户定位点（`<Map showLocation={false}>`），回位按钮回到当前电站；`scope.userLocation` 的说明只写
  「用于添加或编辑自建电站时填入当前位置坐标」，与指引、「数据使用说明」保持一致，不写未实现的用途。
- 后台各栏参考填法：存储期限写「电站坐标随用户保存的自建电站存储，删除电站或删除我的数据后一并删除，未保存时不存储」；
  用户权益写「可在『我的』页退出登录，或通过『删除我的数据』删除全部自建电站及相关记录」；第三方插件选「无」；
  补充说明写用户填写的自建电站信息及用途，并注明不采集手机号、头像与昵称。

## 五、位置权限申请


这是本项目**最容易卡住**的一项。


### 5.1 需要声明的接口

`app.json` 中声明 `requiredPrivateInfos`：

```json
{
  "requiredPrivateInfos": [
    "getLocation",
    "chooseLocation"
  ]
}
```

未声明直接调用会报错，且此项在代码里，容易在提审时才发现漏配。


### 5.2 后台申请

mp 后台「开发管理 → 接口设置」申请开通位置接口，需填写使用场景说明，人工审核。

**说明要写具体**，泛泛而谈容易被驳回。参考写法：

```
用户在「站点 → 我的站点 → 添加场站」表单中点击「当前定位」时，获取一次当前位置的
经纬度填入场站坐标；点击「地图选点」时打开微信地图选择场站位置。
仅在用户主动点击时调用，不在后台获取位置；拒绝授权后仍可手动输入经纬度。
位置信息仅用于上述功能，不做其他用途。
```

配合截图说明触发场景（场站表单的「当前定位」「地图选点」两个按钮）。
隐私保护指引里要列出：位置信息（自建场站坐标）、用户填写的场站信息（名称、坐标、容量、
设备参数、限电规则）。不采集头像与昵称。自建场站按 openid 隔离，生产必须配置
`ENERSIGHT_WX_APPID / WX_SECRET`，见 [10](./10-deployment.md)。


### 5.3 注意

- 后台申请与 `requiredPrivateInfos` 声明**两者都要**，缺一不可
- 申请被驳回可以补充材料重提，但会拖后整体排期
- 建议在开发早期就提交申请，不等功能完成

## 六、生成式 AI 合规


### 6.1 监管要求

面向境内公众提供生成式 AI 服务，受《生成式人工智能服务管理暂行办法》约束，
涉及备案/登记要求。

> **具体适用范围与本项目是否需要单独备案，必须由法务确认。**
> 技术侧的判断（见 [08 §2.1](./08-ai-design.md)）是：
> 使用境内已备案模型厂商的服务，可降低但不必然免除自身的合规义务。


### 6.2 技术侧应做的

无论法务结论如何，以下四条都应做：

| 项 | 做法 |
| --- | --- |
| 模型选型 | 优先境内已备案模型，见 [08 §2.2](./08-ai-design.md) |
| 内容安全检测 | AI 输出落库前过微信内容安全接口，见 §七 |
| 输出可追溯 | 每条 AI 输出留存 prompt、模型、时间，见 [08 §八](./08-ai-design.md) |
| 兜底可关停 | AI 能力可通过配置开关整体关闭，降级到规则模板 |

最后一条很重要：一旦出现合规问题，要能在不发版的情况下关掉 AI。
[08 §六](./08-ai-design.md) 的规则模板降级路径正好复用为这个开关。

## 七、内容安全


AI 生成的文本会直接展示给用户，需过内容安全检测。

```
AI 生成  →  微信内容安全接口检测  →  通过则落库缓存
                    ↓ 不通过
              丢弃并降级为规则模板，记录告警
```

要点：

- 由**服务端**调用微信内容安全接口，不在小程序端做
- 检测发生在**生成后、落库前**，不在用户请求路径上
  （AI 输出本就是预生成的，见 [08 §三](./08-ai-design.md)）
- 用户自填的站点名称同样需要检测

> 规则模板的输出是固定文案，不需要每次检测，上线前人工过一遍即可。

## 八、域名与网络配置


mp 后台「开发管理 → 服务器域名」配置：

| 类型 | 用途 | 本项目 |
| --- | --- | --- |
| request | 接口请求 | BFF 域名 |
| uploadFile | 上传 | V1 暂无 |
| downloadFile | 下载文件 | 视图层图片加载方式而定 |
| socket | WebSocket | V1 暂无 |

要求：

- HTTPS，且证书有效
- 域名已 ICP 备案
- 每类域名数量有上限，不要把 CDN 子域名铺开配置

> **待验证（并入 [05 §6.7](./05-architecture.md) 的 spike）**：
> 图层图片通过 `ground-overlay` 加载时，CDN 域名是否需要配置为 `downloadFile` 合法域名。
> 若需要，CDN 域名也必须备案，这会影响 CDN 选型 —— 必须在第 1 周确认。

## 九、时间线与前置依赖


**关键：哪些事必须现在就启动。**

```
第 0 周  ├── 注册企业主体小程序、选类目        ← 立即
         ├── 提交小程序备案                    ← 立即，周期最长
         ├── 域名 ICP 备案 + 服务器采购        ← 立即，与上并行
         └── 提交位置接口申请                  ← 立即，不等功能完成

第 1 周  ├── 地图 spike（含 downloadFile 域名验证）
         └── 法务确认生成式 AI 备案义务

第 2 周+ ├── 配置隐私保护指引
         ├── 配置服务器域名（依赖 ICP 备案完成）
         └── 接入内容安全检测

提审前   ├── 全量走查本文档 §十 检查清单
         └── 准备审核说明与测试账号
```

| 前置项 | 阻塞什么 |
| --- | --- |
| 域名 ICP 备案 | 小程序无法请求任何接口，真机联调全部阻塞 |
| 小程序备案 | 无法提交审核发布 |
| 位置接口申请 | 定位功能无法真机验证 |
| 类目选定 | 位置接口能否申请 |

> 域名备案未完成期间，真机调试可临时勾选开发者工具的
> 「不校验合法域名」进行本地联调，但**不能作为长期方案**，
> 且真机预览与体验版仍受限制。

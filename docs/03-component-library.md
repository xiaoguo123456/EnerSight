# 03 组件库规范 · Component Library

> EnerSight AI 新能源气象遥感分析平台 · 文档包 V1.0
>
> 本文档已对照 `packages/ui/` 下的 6 张设计稿更新，补齐设计稿中出现但原规范未收录的组件。


## 一、基础组件


### AppHeader


用途：

一级页面顶部。


包含：

- Logo
- 标题
- 副标题
- 通知
- 用户入口


视觉：

山景 + 光伏板氛围背景图，右侧手写体品牌文案。


标题随页面变化：

| 页面 | 标题 |
| --- | --- |
| 首页 | AI新能源气象遥感分析平台 |
| 地图 | 新能源地图 |
| 预警 | AI新能源气象遥感分析平台 |


---

### PageHeader


用途：

二级页面顶部。


包含：

- 返回按钮
- 标题
- 副标题（可选）
- 氛围背景图


应用：

- 站点详情
- AI分析报告


---

### BottomTabBar


全局唯一底部导航。


固定：

```
首页
地图
预警
站点
我的
```


状态：

Active：

蓝色

Inactive：

灰色


规则：

二级页面保留底部导航，父级 Tab 维持激活态。


---

### SectionHeader


模块标题行。


结构：

```
图标 + 标题                    查看更多 >
```


应用：

24小时趋势、今日预警、快捷入口、预警记录、运营建议、数据摘要。


---

### SegmentedTabs


横向筛选切换。


形态：

全圆角胶囊，激活项蓝底白字。


变体：

| 变体 | 应用 | 示例 |
| --- | --- | --- |
| 纯文字 | 趋势指标切换 | 辐射（W/m²）/ 风速（m/s）/ 云量（%） |
| 带计数 | 站点类型筛选 | 全部（2）/ 光伏（1）/ 风电（1） |
| 带状态点 | 预警等级筛选 | 全部 / ●轻度 / ●中度 / ●重度 |


---

### StatusBadge


运行状态徽章。


结构：

```
状态点 + 文字
```


状态：

| 状态 | 颜色 |
| --- | --- |
| 运行正常 | 绿色 |
| 设备待机 | 蓝色 |
| 设备异常 | 红色 |


---

### RiskBadge


风险等级徽章。


等级：

```
轻度风险    中度风险    重度风险    解除预警
```

配色见设计规范「状态色」。


---

### TrendDelta


环比标签。


结构：

```
较昨日 ↑12%
```


规则：

- 上升红色，下降绿色
- 无昨日数据时整体隐藏


---

### InfoTooltip


说明图标「?」。


应用：

新能源环境指数、综合判断，点击说明计算口径。


---

### SearchBar


搜索框。


占位文案：

```
搜索城市 / 坐标 / 站点
```


应用：

地图页顶部。


---

### FloatingActionButton


悬浮主操作按钮。


形态：

全圆角胶囊，蓝色，图标 + 文字。


应用：

站点列表「+ 新增站点」。


---

## 二、数据组件


### MetricCard


指标卡。


展示：

```
图标

标题

数值

趋势
```


应用：

- 温度
- 风速
- 云量
- 辐射


扩展：

辅助行可放天气现象文案（晴转多云）或环比（较昨日 ↑12%），二选一。


---

### MetricGrid


四宫格容器。


规则：

- 等宽四栏
- 竖线分隔
- 固定四项，不换行不滚动


应用：

首页实时数据、地图底部面板、站点详情当前天气、站点卡指标、数据摘要。


---

### EnergyScoreCard


新能源指数。


结构：

```
标题

分数

等级

影响因素
```


设计稿实现形态：

```
叶子图标 + 标题 + 说明入口

92分

一句话结论
```


视觉：

浅绿渐变背景 + 远山插画 + 手写体装饰。


---

### TrendChart


趋势图。


类型：

- 折线图
- 面积图


数据：

- 辐射
- 风速
- 云量


交互：

- 指标 Tab 切换
- 点击数据点显示悬浮值气泡与纵向虚线


---

### DataSummaryGrid


数据摘要四宫格。


每项结构：

```
彩色圆形图标

标题

数值 + 单位

环比
```


应用：

AI分析报告数据摘要（发电量 / 等效利用小时 / CO₂减排 / 收益预估）。


---

## 三、地图组件


### MapContainer


基础地图。


包含：

- 底图
- Marker
- 图层


---

### MapLayerControl


图层控制。


固定：

```
云图
风场
温度
辐射
站点
```


形态：

右上竖排，图标 + 文字，激活项蓝底白字。


---

### SatelliteOverlay


卫星图层。


支持：

- 云图
- 红外
- 水汽


默认按当地昼夜自动切换可见光与红外。


---

### MapLegend


图层图例。


结构：

```
标题（含单位）

色带

刻度
```


规则：

随激活图层同步切换。


示例：

```
辐射强度（W/m²）
0  200  400  600  800  1000
```


---

### MapZoomControl


缩放控件。


结构：

```
+
−
```


---

### MapLocateButton


定位按钮。


行为：

地图回到当前站点位置。


---

### MapScaleBar


比例尺。


位置：

右下角，随缩放级别变化。


---

### MapMarker


地图标记。


变体：

| 变体 | 说明 |
| --- | --- |
| 当前位置 | 蓝色圆点 + 名称气泡 |
| 站点标记 | 按类型区分图标，按状态区分颜色 |
| 聚合标记 | 同屏站点过多时显示数字簇 |


---

### MapBottomSheet


地图底部面板。


形态：

可上下拖拽，顶部有拖拽指示条。


内容：

- 站点名称 + 状态 + 详情入口
- 地址
- 四宫格指标
- AI 提示条


---

## 四、业务组件


### StationSelector


站点选择器。


结构：

```
缩略图 + 站点名称 + 下拉箭头

所在区域
```


应用：

首页顶部、地图顶部。


---

### StationCard


站点卡。


展示：

- 图片
- 名称
- 类型
- 状态
- 指标


完整结构：

```
缩略图 + 名称 + 详情箭头 + 状态徽章 + 更多菜单

装机容量

地址（行政区 + 经纬度）

四宫格指标
```


四宫格指标：

```
今日发电    实时功率    累计发电    减排量
```

光伏与风电共用一套指标。

> 设计稿含储能站卡片（另一套指标），V1 不实现。


---

### AddStationCard


添加站点卡。


结构：

```
+ 图标 + 标题 + 副标题

从公开电站选择  >
```

只有这一种方式（[01 §六](./01-prd.md)）。站点列表页用的是压缩成一行的入口条，完整卡片留给空态。


视觉：

浅绿渐变 + 右侧地图插画。


---

### AlertBanner


首页预警条。


展示：

- 等级图标
- 标题
- 说明
- 查看更多入口


规则：

仅展示当日最高等级一条，无预警时不渲染。


---

### AlertCard


预警卡。


展示：

- 风险等级
- 标题
- 原因
- 影响


完整结构：

```
等级图标 + 等级徽章 + 发布时间

标题

成因与影响说明 + 插画
```


---

### CloudMotionStats


云团外推三宫格。


固定三项：

```
云团距离      移动方向      预计影响时间
```

每项含主值 + 辅助说明。


---

### SatelliteCloudCard


卫星云图卡。


结构：

```
左上：数据类型 + 观测时间
右上：全屏按钮
地图内：站点标记
右下：云量强度图例
```


---

### AlertRecordList


预警记录列表。


单条结构：

```
等级图标 + 标题 + 等级徽章 + 发布时间

摘要说明                              >
```


包含「解除预警」态（绿色对勾图标）。


---

### AIReportCard


AI报告卡。


展示：

- 总结
- 风险
- 建议


---

### TimelineAnalysis


时段分析。


结构：

```
上午 06:00-12:00 | 下午 12:00-18:00 | 晚间 18:00-24:00

———●———————————●———————————●———

天气概况         天气概况        天气概况
发电条件         发电条件        对次日影响
```


规则：

节点与连接线按该时段风险等级配色。


---

### SuggestionList


运营建议列表。


结构：

```
① 建议内容
② 建议内容
③ 建议内容
```


序号为绿色圆形底，通常 3 条。


---

### QuickEntryGrid


快捷入口。


单项结构：

```
彩色圆形图标

标题

副标题
```


变体：

| 变体 | 应用 | 项数 |
| --- | --- | --- |
| 四项横排 | 首页快捷入口 | 4 |
| 两项横排 | 站点详情快捷操作 | 2 |


---

# 移动端界面紧凑化调整记录

## 本轮范围

基于 `feat/user-stations-7d-forecast` 创建时的提交 `4c6dd1b`，工作树分支为 `codex/compact-mobile-ui`。已实现首页、电站目录、详情、分析报告、我的、添加／编辑电站、预警和地图的紧凑化。共享趋势图绘制修正同时作用于详情页。

首页改为电站身份、范围与模型、所选日电量与峰值、功率曲线、七日电量、气象指标、可展开气象趋势。模型详情仍可在选择器与预测口径中查看；预测失败、降级估算和参数不足仍直接显示。数据明细在曲线标题旁展开，CSV 导出放在明细区域，保留原有登录要求。全目录数据归到「全部电站」。

我的电站为空时仅保留归属切换、空状态及一个添加按钮；有数据时恢复搜索、类型筛选和顶部添加入口。筛选到零条仍保留筛选与清除操作，不误显示为没有自建电站。游客、加载失败与真实空列表分别呈现。

## 验证记录

- 小程序 TypeScript 检查通过。
- H5 与微信小程序构建通过；构建工具仍有现有 Sass 弃用提示。
- 图表测试 3 项通过，覆盖真实时间、缺测、高分屏画布清理和单／双曲线气泡边界。
- 小程序测试共 18 项，17 项通过。失败项为「所有已注册页面开启好友分享，朋友圈入口只在首页」：`pages/login/index` 未设置分享开关。在原工作区单独重跑同一测试，确认同样失败，本轮未修改登录页或分享配置。
- Playwright 使用拦截的模拟数据，在 320、375、390、430px 手机宽度检查首页；无横向溢出，无页面运行时异常。390px 预览的完整功率曲线底部约为页面第 532px。
- 已检查切日联动、范围切换、明细与导出入口、气象趋势展开记忆、指标切换、真实空列表、有数据列表、筛选无匹配、加载失败、游客引导、刷新失败保留旧数据，以及光伏、风电、限电和容量待核实状态。

- 预警无风险时不请求卫星序列，手动展开后请求，新预警自动展开；编辑已有跨夜检修时自动展示约束，收起再展开仍保留周二／周四规则。

# EnerSight AI 新能源气象遥感分析平台

项目文档包 V1.0

## 产品一句话定位

基于气象数据、卫星遥感数据、地理空间数据与 AI 分析能力的新型能源环境分析平台，帮助用户快速了解某一区域的新能源环境、未来气象变化、云层影响与发电风险。

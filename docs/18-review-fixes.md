# UI、算法与数据一致性修复及验收

日期：2026-09-13。针对 [本次分支审查](./reports/branch-review-2026-09-13.md) 中可以由当前代码直接修复的问题。本节记录本地修复与验收范围；提交及测试环境发布状态见部署记录。

## 修复内容

| 问题 | 修复后的行为 |
| --- | --- |
| 编辑名称清空设备参数 | 摘要及详情返回倾角、方位角、轮毂高度；表单完整回填、仅 PATCH 改动字段；未改位置时不重复转换坐标。自定义星期集合也原样保留。 |
| 风电密度修正影响切出 | 实际轮毂风速决定切入、切出边界，密度等效风速只用于边界内出力计算；低、高密度和自定义曲线均覆盖测试。地面气压／2 米气温仍是密度近似，已明确提示。 |
| 周五跨夜限电匹配错误 | 周五 22:00–次日 02:00 覆盖周五晚间及周六凌晨，以时段开始日匹配星期。 |
| 旧气象被标成新批次 | 全目录天气缓存校验模型起报批次，保留原始及逐格拉取时间；续算不延长旧输入寿命。已确认批次发生切换时停止纳入新响应，等待下次重新计算。 |
| 单站邻站串用、跨日窗口不足 | 单站按精确坐标缓存；校验当地日期，跨日重新取数；多取一天用于最后一天光伏的午夜区间边界。 |
| 各日覆盖率沿用今日 | 每日分别返回覆盖数、容量、缺测数和状态；今日缺测的电站仍可贡献未来有效日。增加七天共同覆盖电站的固定样本电量比较。 |
| 昨日记录冒充今日／当前 | 按记录所保存的当地时区筛选今日；超过一小时的功率隐藏，累计值继续保留；upsert 明确更新记录时间。 |
| 配置变化仍复用旧计算 | 算法修订及网格、损耗、设备默认参数、预测天数和日期切换设置参与计算指纹；目录数量／最新修订时间参与快照有效性校验。 |
| 汇总舍入放大 | 区域单位容量曲线保留计算精度，在乘场站容量前不再取三位小数。 |
| 留档不完整或覆盖旧签发 | 单站留存完整七天输出、设备配置、计算设置、小时及 15 分钟输入；全目录留存原始网格天气、逐格拉取时间、参与电站及各站覆盖日期。签发记录引用不可变输入 ID，保留曲线、版本、批次和逐日覆盖。 |
| 长期锁增长、上游预算分散 | 无持有者或等待者的缓存锁及时清理；同进程气象请求共享滑动窗口预算，计入坐标／变量／天数，并遵循 429 Retry-After。 |
| 首页默认空白 | 默认优先可计算的目录站；不可计算时显示原因和选站入口，隐藏空柱图区；无站点时提供添加／选择入口。 |
| 刷新和批次显示不一致 | 刷新同时更新 home 和七天 outlook，顶栏采用正在展示的预测批次；刷新失败保留结果并明确提示。无法确认自动模型时不再固定显示 ECMWF。 |
| 七天条过密、小站曲线失真 | 七列只放日期和电量，选中日说明移至下方；窄屏日期缩短；曲线按范围采用 kW／MW／GW，标明 15 分钟插值及后 3 天参考。 |
| 上网时段不可见 | 可发／预计上网双曲线、受约束区间底色、双值提示；提供可展开的逐时文本数据，提高坐标轴对比度及七天按钮辅助标签。 |

共同样本开关仅控制七天电量对比条。选中日主值、曲线和区域贡献仍展示该日所有可算电站，标题标明“已覆盖电站合计”。

## 接口与数据库

- `StationSummary` 新增可空的 `tilt / azimuth / hub_height`。
- 预测增加 `calculation_version`、补值标记 `estimated`；`FleetDay` 增加 `covered_count / covered_capacity_kw / failed_count / status / common_energy_kwh`。
- `FleetPrediction` 增加 `batch_stamp / catalog_revision / common_covered_count / common_capacity_kw / input_archive_id`。前端类型已通过 OpenAPI 重新生成。
- 新增迁移 `a713d91e2001`，在 `daily_generation` 中增加 `timezone / calculation_version / weather_model`。升级环境需在启动新版后端前执行：

```sh
cd packages/server
.venv/bin/alembic upgrade head
```

旧记录时区按项目既有中国站点范围默认上海时区，历史版本与模型保持空值，不能倒填为本次新版本。缓存按计算指纹自动失效，无需删除历史文件。

新增留档位于配置数据目录的 `prediction-outlook/` 和 `prediction-fleet-inputs/`；全目录签发位于 `fleet-history/leads/`。输入采用内容指纹去重，历史文件不随两天临时天气缓存一起删除。部署时应保留这些目录并按历史数据需求安排存储容量。

浏览器实际验证了：默认跳过容量来源未核验的大站；编辑仅改名称后原倾角 20°、方位角 160°、WGS84 坐标和限电规则不变；3 kW 电站显示 kW 双曲线及约束区域；点击刷新后 home、outlook 请求各增加一次；缺测日覆盖由 2/3 变为 1/3，容量覆盖同步变化；共同样本固定 1 座电站比较七日天气变化。

后端测试命令为 `env -u PROJ_DATA -u PROJ_LIB .venv/bin/pytest -q`。本机 Conda 的 PROJ 数据库与虚拟环境 rasterio 不兼容，仅对测试进程移除两个环境变量后通过，未修改系统设置。构建有既有 Sass 弃用提示，测试有依赖弃用提示，均未阻止通过。

# 02 UI 设计规范 · Design System

> EnerSight AI 新能源气象遥感分析平台 · 文档包 V1.0
>
> 本文档已对照 `packages/ui/` 下的 6 张设计稿更新。
> 标注「基准色」的为原始规范定义值；标注「取自设计稿」的为从设计稿补充提取，
> 落地前建议与设计确认十六进制值。


## 一、设计方向


整体风格：

新能源科技 + 地理信息 + AI。


关键词：

- 清洁
- 专业
- 数据化
- 可信


视觉特征（自设计稿归纳）：

- 浅色底 + 白色卡片，大量留白
- 自然实景图（山景、光伏板、风机）作为顶部氛围
- 绿色代表能源与环境，蓝色代表数据与操作
- 关键数字放大加粗，作为每张卡片的视觉重心
- 手写体点缀传递品牌温度

### 环比配色

环比是次要信息，用较柔和的色值（上升 `#dc2626`、下降 `#15803d`），
字号 10px，不与主数值抢注意力。


```
上升 ↑   Danger Red

下降 ↓   Energy Green
```

> 此处红绿表示「变化方向」，不表示好坏，实现时不要按股票涨跌习惯反转。
> 云量上升同样用红色，辐射上升也用红色。

## 三、字体规范


| 层级 | 字号 | 字重 | 应用 |
| --- | --- | --- | --- |
| **Hero 数字** | 40px | 800 | 每页唯一：环境指数分值。其他数字不得接近此尺寸 |
| 页面标题 | 22px | 800 | 顶栏标题（站点名 / 预警中心） |
| 模块标题 | 15px | 700 | 24小时趋势、运营建议 |
| 数据数字 | 22px | 700 | 四宫格主数值 |
| 次级数字 | 17px | 700 | 站点卡次要指标 |
| 正文 | 14px | 400 | 卡片描述、一句话结论 |
| 辅助 | 11px | 400 | 标签、时间戳、副标题 |
| 微 | 10px | 500 | 单位、环比 |

> 层级靠**尺寸差**拉开：Hero 约为四宫格数字的 1.8 倍。
> 差距不够时用户分不出主次，不要靠加边框加阴影补救。


补充规则：

- 数值与单位同行，单位字号约为数值的 35%，颜色降两级
- 所有数字用等宽数字（`tabular-nums`）并收紧字距（-0.02em），多位数才对得齐
- 千分位分隔符必须保留（2,400 / 1,008 / 6,320）
- 手写体与品牌口号不承载功能信息，**顶栏不放品牌名** —— 用户已在 app 内，
  这块位置给站点名或页面标题

## 六、阴影规范

取自设计稿。

| 层级 | 应用 | 说明 |
| --- | --- | --- |
| 无阴影 | 页面内常规卡片 | 靠背景色区分层次 |
| 轻阴影 | 地图浮层控件、图例、图层切换器 | 需从地图上浮起 |
| 中阴影 | 地图底部面板、悬浮按钮 | 明确的浮层关系 |

原则：

浅色背景上的卡片优先用留白和描边区分层次，不叠加重阴影。

## 九、布局原则


### 一页一个 Hero

每个页面只有一个视觉焦点，其余内容按「支撑 → 辅助」退后：

| 页面 | Hero | 支撑 | 辅助 |
| --- | --- | --- | --- |
| 首页 | 环境指数 | 四宫格（8px 紧贴） | 趋势、预警、入口 |
| 预警 | 当前预警标题 | 云团外推三宫格（「预计影响时间」用主色） | 云图、记录 |
| 站点 | 站点卡「今日发电」 | 其余三项（灰色次级） | 添加入口 |
| AI 报告 | 综合判断 | 今日情况 | 风险、建议、摘要 |

间距节奏：逻辑组之间 16px，组内 8px。同组卡片紧贴才读得出「这是一组」。


### 按下态

所有可点击的卡片与按钮必须有按下反馈（`scale(.985)` + `opacity .85`），
否则像静态图。小程序用 `hover-class`，H5 用 `:active`。


### 地图优先


地图相关页面：

地图占主要空间。

控件浮于地图之上，不挤压地图面积。


### 数据卡片辅助


数据使用：

卡片化展示。

同类指标固定四宫格，等宽分栏，竖线分隔。


### AI解释优先


不要只展示：

```
Cloud Cover 65%
```


转换：

```
下午云量增加，
可能影响发电效率。
```


### 数字优先


每张数据卡的视觉重心是数字本身：

```
标签（小）

数值（大）+ 单位（小）

辅助说明 / 环比（小）
```


## 2026-09 产品界面修订

本轮以目录查找效率和可信数据表达为先。公共目录采用白底、细分隔线的连续列表，名称最多两行，地区独立一行，类型与容量分开；不重复展示“查看”按钮与大色块图标。顶部搜索和类型、地区筛选保持可达，最近浏览仅存本机。

正文 14–16px，辅助说明 12–13px，关键浅灰文本改为 #64748B；图标采用 24 坐标系、1.75 描边，选中通过蓝色区分，不统一加填充。卡片圆角 12–16px。默认普通正文应达到 4.5:1 对比度。红绿仅表示有明确语义的风险与状态；气象变化方向用中性色箭头。

无设备遥测时显示“目录运营中”，不显示“设备运行正常”。无预警表示未触发规则，不能等同发电条件良好。缺测显示“—”。指数与报告提供解释、时间和估算口径。只显示可完成的操作入口。
